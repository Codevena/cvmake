## Recommendations

All closed. The four that stood partial the longest, and how:

- **Photo pipeline** — aspect ratio in `1a032cc`; EXIF rotation turned out to be
  present already, so the audit line was pessimistic; atomic writes in `8d8ef7a`,
  where the helper itself was leaking a temp file into a served directory.
- **Schema invariants** — URL schemes and unique `sectionOrder` in `1a032cc`;
  real calendar dates and `end >= start` in `14ea195`, together with the
  importer, which emitted `2021-02-31` and would then have failed at build.
- **Hermetic visual suite** — local fonts in `1a032cc`; production CSS
  composition and browser reuse in `64b686b`. The print medium was deliberately
  left out: measured across four templates, switching it moves 0.000000 of the
  pixels, because no template has a `@media print` block.
- **Documentation numbers** — the "3+ color palettes" claim was wrong in three
  places, one of them inside the published `@codevena/cvmake-cli`.
